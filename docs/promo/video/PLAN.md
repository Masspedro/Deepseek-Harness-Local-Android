# DSH Mobile 宣传视频分镜计划

最终落地版本：Remotion 工程 `1.1.0`，44 秒、60fps。竖屏 1080×1920，横屏 1920×1080，各 2640 帧。两支成片已渲染并由用户验收；本文件仅校准旧 42 秒草案与已交付工程的差异，不要求重新制作或渲染。

## 创意与运动语言

主线是“把路径拉直”：先给出完整 Node.js Agent 引擎在 Android 原生运行的钩子，再展示长链与直线；中段完整交代体积口径与原生外壳证据，后段以模块网络和换装状态机表现工程深度。

画面使用 MATERIALS.md 深色主题令牌、Segoe UI / 微软雅黑 / Consolas。所有图形与文字由 React/CSS/SVG 绘制，动效依 `useCurrentFrame()` 计算。局部进场使用小幅 spring 和统一缓出曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，背景低对比缓慢漂移；切镜采用方向推进与交叠淡化。截图与录屏仅在代码绘制的手机框内呈现。

## 数据与素材边界

- 所有主动上屏数字和字幕集中在 `remotion/src/data.ts`，对应 MATERIALS.md 的逐项出处见 `CHECKLIST.md`。
- 3.4 秒只属于一加 15T 用户实测，不拿模拟器录屏证明该测量；不画竞品未同条件实测的性能数值。
- 三个体积口径完整保留比本作小的产品；简单包 24 MB 不能脱离首启下载 128 MB，首次总量约 152 MB。
- bionic 路线有其他同类，功能比较只使用特征匹配下界措辞，不说竞品绝对缺失。
- `09-main-clean.png` 实际是启动遮罩，最终未用于伪装就绪画面；失败对话录屏未使用。
- 竖屏关键内容置于顶部 85% 安全区；横屏采用独立构图分支。
