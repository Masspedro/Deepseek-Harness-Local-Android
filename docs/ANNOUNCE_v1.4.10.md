# DSH Mobile v1.4.10 更新公告

v1.4.10 上架喵～ 这一版主要修一个我自己搞出来的回归，另外把大家提的角色限制放开了。

## 🔴 工作区选不了外部文件夹 —— 修好了（我的锅）

有宝宝反馈：更新到 1.4.8 / 1.4.9 之后，明明已经给了存储权限，工作区还是选不了外部文件夹，点「选择工作区」什么都不发生。

**这是我 1.4.8 引入的问题**，原因很具体：目录选择器在引擎里是**一对**插件 —— 一个负责后台服务，一个负责**界面上的选择框**。原版会自动把两个一起挂上，我为了绕开另一个 bug 改成手写配置，结果**只写了后台那一半**。

于是服务确实在跑（所以健康检查一直显示正常），但界面上根本没有那个框 —— 你点它当然没反应。

更该反省的是我当时的验证方式：我验证的是「健康检查显示正常」，可那个指标只反映**后台服务**，不反映**界面**。用户看得见的东西，我没验证看得见的那一层。

**现在补上了**。实测抓页面看，修复后确实加载了那个界面组件（修复前没有这一项）。

如果你在 1.4.8 / 1.4.9 上遇到这个问题，**更新后直接恢复，不用重装也不用清数据**。

## 🎭 人物角色不再被写死

有宝宝说想用特定人格、语气、角色来聊天，但提示词把角色写得很死。

先澄清一下：提示词里其实**没有**全局人格设定。真正碍事的是两处措辞 —— 一处用了「You are ...」这种句式（本意是说 UI 自动化谁干什么活），另一处写了「角色扮演只在对话内」，本意是区分「改配置文件」和「对话内扮演」，但那个 only 读起来像限制。

现在改成明确的：

- 分工说明不再用身份句式，并注明「与人格、语气无关」；
- 新增一段说清楚：**人格、语气、角色由你决定**；环境说明是说明书不是人格；不能拿这份文档当拒绝理由；**对话内的角色请求优先**；别擅自加免责声明和出戏说明。

**保留没动的两条**（这些是真实风险边界，跟角色设定没关系）：

- 不许改 App 管理的那段配置、不许塞隐藏指令文件；
- 金融类应用默认拒绝、不许让注入的输入变得无法检测。
