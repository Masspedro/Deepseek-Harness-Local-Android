# DSH Mobile v1.4.22

> 手机版 WebUI。感谢社区贡献的这个移植包——它把 WebView 里原本的桌面版界面重排成了
> 手机形态，并统一了原生壳的配色。

## 手机版 WebUI（可选，默认启用）

WebUI 现在会自动切换成手机布局：

- **抽屉式会话列表**：侧边滑动唤出，不再是桌面版那条窄窄的侧栏；
- **全屏面板**：文件和设置以全屏面板呈现，不再挤在右侧小栏里；
- **固定底部输入条**：输入框常驻屏幕底部，配合软键盘的 resizes-content 行为；
- **手机头部状态栏**：当前工作区/模式以胶囊形式展示在顶部；
- **手势**：左右滑动切换面板；
- **图片/文件查看**：点开即全屏预览。

它只在触屏窄屏（`pointer: coarse` 且宽度 ≤1023px）下生效——平板横屏、外接鼠标键盘
的环境仍是桌面布局，互不干扰。

### 会话删除

手机版抽屉里长按会话可以删除。删除不是物理抹除：日志会移入 `.sessions-trash/`
并写一份 manifest，可随时取回。路径做了逃逸检查、失败会回滚重命名。

## 原生壳配色统一

设置页、扩展中心、插件中心、状态浮层、诊断页等原生界面的强调色，从原来的天蓝
`#7DD3FC` 统一为 DSHA 的靛蓝 `#4F6EF7`。新增集中的色板文件便于后续统一调整。

## 技术说明

- 该 WebUI 以客户端插件形式挂载（`android-plugins/dsh-web-mobile`），随引擎启动部署、
  走插件的 overlay 注入机制，与既有的四个窄屏适配插件同一套路径；
- 宿主侧还注册了一个响应压缩（仅 JSON、有大小上限、不动 SSE）和一条同源校验的
  会话删除路由，两者都复用了引擎已有的鉴权链；
- 插件源码以 MIT 许可从上游 `dsh-web-mobile` 适配，LICENSE 随包保留。

## 兼容性

直接覆盖安装即可，会话、工作区、凭据、插件全部保留。若想回到桌面版布局，可在
平板/桌面模式（横屏或接键鼠）下使用。
