# DSH Mobile v1.4.20

> 本版四项修复全部来自社区实机报告（感谢 @yiming-0098 的三份高质量分析）。

## Android 10 存储权限修复（#42）

`WRITE/READ_EXTERNAL_STORAGE` 的声明上限从 Android 9 提升到 Android 10（API 29）。
此前 API 29 设备处于「权限不存在、授权入口也不存在」的死角——「所有文件访问」是
Android 11 才引入的，而普通存储权限又被声明为仅到 Android 9。现在导出、写入
Download/、终端读写 /sdcard 在 Android 10 上可正常授权。

## 开 VPN 时单文件下载失败（#44）

开启 VPN 后，文件分享插件的单文件下载 100% 失败（打包下载正常）。根因是系统下载
管理器作为独立进程，其连接被绑到 VPN 网络，访问本机回环地址拿不到结果。

现在**回环地址的下载不再经过系统下载管理器**：由 App 自身流式下载（后台线程、
携带登录会话、边下边写不占内存），与 VPN 状态无关。外部 URL 仍走系统下载管理器。

## WebUI 复制按钮无反应（#43）

`navigator.clipboard.writeText` 在 WebView 里常被焦点/激活限制拒绝，而页面把异常
吞掉，用户感知就是「按钮坏了」。现在：

- 注册了原生剪贴板桥，并在每次页面加载后注入降级链：原生 API → 原生桥 →
  兼容模式复制，三条路全失败才放弃；
- WebView 保持可聚焦，降低被拒概率。

## 错误提示可读化（#47）

扩展下载在个别情况下会抛出「List is empty」这样的内部异常名，完全不可读。现在
给出可操作的错误说明。

## 其它

- README 三语安装包体积描述修正（实测约 227 MB，安装后约 720 MB）；

- WebView 96 的 `throwIfAborted` 全链报错修复（polyfill v4）随本版覆盖更多用户。
