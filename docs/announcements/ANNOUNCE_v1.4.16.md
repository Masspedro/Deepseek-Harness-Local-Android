# DSH Mobile v1.4.16 更新公告

v1.4.16 上架喵～ 这版主打**插件兼容性**，还修了一个挺严重的老毛病。

## 🔌 插件两个老问题都解决了

**问题一：装插件报 `ERR_PNPM_IGNORED_BUILDS`**

插件中心用的包管理器默认**拒绝执行**插件的构建脚本。带原生模块的插件（better-sqlite3、sharp、node-pty 这些）会「装成功但二进制没编译」——装了个用不了的。而且这类模块在安卓上基本编译不出来。

**现在的做法**：点安装先做检测，发现插件需要原生代码就弹窗说清楚，列出具体原因（比如"依赖 node-addon-api"），你选"仍然安装"还是取消。纯 JS 插件照常直接装。

**问题二：装完插件 App 起不来**

坏插件可能让引擎启动就崩，之前要折腾很久。

**现在的做法**：连续 2 次启动失败就自动摘掉最近装的那个插件（只摘一个、先备份），引擎自动恢复。**实测从崩溃到恢复约 40 秒，全程不用你操作**。摘掉的插件有备份，可以找回。

## 🔧 顺带修了个严重的：引擎崩溃后不再误报

审查发现一个自相矛盾的 bug：引擎健康跑超过 5 分钟后一旦崩溃，自动重试会被误判成「启动超时 N 分钟」直接放弃——**等于自动重启这个功能一直是坏的**，只是之前没暴露。

修好后实测：强杀引擎进程，9.3 秒自动恢复。

另外这轮整体代码审查修了 3 个严重 + 5 个中等问题，包括并发装插件可能损坏配置、CI 构建校验从未生效（意味着从这版起 CI 构建和本地完全一致）等。
