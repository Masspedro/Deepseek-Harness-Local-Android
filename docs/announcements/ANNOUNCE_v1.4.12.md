# DSH Mobile v1.4.12 更新公告

v1.4.12 上架喵～ 这一版有两件大事：**启动快了一倍**，还有大家要的**数据导出**。

## 🚀 启动速度：52 秒 → 24 秒

有宝宝反馈「1.4 之后启动怎么优化都慢，低配手机宁愿用回 1.3」。我查下来，**不是新引擎慢，是我们的打包方式退化了**。

新引擎把依赖改成「每个包各自带一份完整依赖」，结果每个包里都嵌了一份完整的 zod —— **3 万个重复文件**。文件数从 1.3 的 1.4 万变成 4.5 万，冷启动那 40 多秒基本都耗在解压这些重复文件上。

| | 解压 | 引擎就绪 | **总计** |
|---|---|---|---|
| 之前的 1.4 | 41.99s | 9.78s | **52.17s** |
| 现在的 1.4.12 | **11.81s** | 4.64s | **23.63s** |

顺带 **安装包也从 241MB 降到 185MB**。

更该反省的是：去重的脚本和成品其实早就做好了，但打包脚本一直没引用它——所以我们一直在发带 3 万份冗余文件的包，还以为是「优化不下去」。

## 📦 新增：数据导出

**设置 → 其他 → 导出数据**，把对话、工作区和工作区列表打成一个 zip，存到你选的位置。

**包含**：对话、工作区文件（含空目录）、工作区列表
**不包含**：API 密钥、登录态、服务商配置、社区插件、已装的扩展

所以换机后：对话和工作区直接回来了，但**需要重新登录、重新配置服务和插件**。

几个刻意的设计：

- 不跟随符号链接（不会把链接指向的外部内容偷偷打进包）
- **失败就整体失败**，不会给你一个「看起来成功、其实缺一半」的备份
- 危险情况明确报错，比如工作区目录指向不存在的位置时，直接告诉你「points to a missing location」，而不是导出一个空包
- 每一步都记进日志，出问题能查

这个功能是群友 **@henryz78** 做的。他上个月还帮我们修了「重启后永久卡住」那个大 bug，这次又主动提了 PR，测试做得比我要求的还细（中文文件名、空目录、多层 node_modules、各种软链都测了）。**已经是正式的仓库贡献者了**，谢谢喵～
